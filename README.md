# 方块世界 · 网页版 Minecraft（支持联机）

纯前端 Three.js 手写的体素沙盒，带一个零依赖配置的 Node 联机服务端。

## 一、单机玩

双击 `index.html` 即可（`file://` 打开时自动进入单机模式，不连服务器）。

## 二、联机玩

```bash
cd mc
npm install        # 首次需要，装 ws
node server.js     # 默认 3000 端口
```

启动后终端会打印两个地址：

- **本机**：http://localhost:3000
- **局域网**：http://<你的内网IP>:3000 —— 把这条发给同一个 WiFi 下的朋友

改端口：`PORT=8080 node server.js`（Windows 用 `set PORT=8080 && node server.js`）。

> 别人连不上时，先看 Windows 防火墙有没有放行 Node；再确认双方在同一网段。

## 四、联机都同步了什么

- 玩家位置与朝向：每 90ms 上报，对方客户端做插值平滑，附走路的摆臂摆腿动画。
- 方块编辑：挖 / 放都会实时广播；服务端保存编辑历史，后进来的人也能看到大家改造过的世界（地形本身由固定种子生成，各端一致，只有改动需要同步）。
- 聊天与在线玩家列表：右上角显示当前在线的人，新玩家加入 / 离开都有提示。

已知边界：地图是 160×160 的固定小世界；世界改动只存在内存里，服务端重启即还原；没有账号系统，昵称随便起。

## 五、开发 / 测试

```bash
node test-mp.js    # 联机协议回归测试（需先启动 server.js，14 项断言）
node ghost.js      # 幽灵客户端：自动连上并站到浏览器玩家面前，用于离屏联调
```

浏览器带 `?auto` 参数可直接跳过开始页进入游戏（无鼠标锁定），方便自动化截图。
